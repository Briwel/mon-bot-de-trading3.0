Bot de Trading en Direct

Explication du Bot

Ce document explique le fonctionnement du bot de trading en direct que nous avons développé. Il est conçu pour automatiser les transactions sur la paire BTC/USDT en se basant sur une stratégie d'analyse technique.

Explication du Code

Initialisation de l'échange : Le bot se connecte à Binance en utilisant les clés API que vous avez fournies.

Boucle `while True` : Cette boucle fait tourner le bot en continu. À chaque itération, elle exécute les étapes suivantes :

  • • Récupération des données en temps réel : Le bot appelle `get_ohlcv()` pour obtenir les dernières données de prix.
  • • Calcul des indicateurs : Il utilise `talib` pour calculer le croisement des moyennes mobiles (`ma_short`, `ma_long`), l'indice de force relative (`rsi`) et les Bandes de Bollinger (`upper_band`, `lower_band`).
  • • Logique de trading : Le bot vérifie les conditions d'achat et de vente, puis place les ordres.
  • • Pause : Le bot fait une pause de 60 secondes pour ne pas surcharger les serveurs.
  • • Gestion des erreurs : Les blocs `try...except` entourent les opérations critiques pour que le bot ne s'arrête pas en cas de problème.

Stratégies de Trading

Stratégie d'achat

  • •

    Croisement des Moyennes Mobiles (MA) : La MA courte (20 périodes) doit être supérieure à la MA longue (50 périodes).

  • •

    Indice de Force Relative (RSI) : Le RSI (14 périodes) doit être inférieur à 70 pour éviter le surachat.

  • •

    Bandes de Bollinger : Le prix actuel doit être inférieur à la bande supérieure pour éviter les sommets de volatilité.

Stratégie de vente

  • •

    Prise de profit (Take Profit) : Vente si le prix atteint 5% au-dessus du prix d'achat.

  • •

    Stop-loss suiveur : Vente si le prix baisse de plus de 5% par rapport à un sommet atteint.

  • •

    Inversion de la tendance : Vente si la MA courte repasse en dessous de la MA longue, ou si le RSI est suracheté.
