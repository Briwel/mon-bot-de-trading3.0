Bot de Trading en Direct

Explication du Bot

Ce document explique le fonctionnement du bot de trading en direct que nous avons développé. Il est conçu pour automatiser les transactions sur plusieurs paires (BTC/USDT, ETH/USDT…) en se basant sur une stratégie d'analyse technique combinant moyennes mobiles, RSI, Bandes de Bollinger et ATR.

Explication du Code

Initialisation de l'échange : Le bot se connecte à Binance en utilisant les clés API que vous avez fournies.

Boucle `while True` : Cette boucle fait tourner le bot en continu. À chaque itération, elle exécute les étapes suivantes :

  • • Disjoncteur journalier : Avant chaque cycle, le bot vérifie si la perte sur 24 h dépasse 5 % du capital. Si c'est le cas, tout nouveau trade est suspendu jusqu'à la fin de la fenêtre de 24 h.
  • • Récupération des données en temps réel : Le bot appelle get_ohlcv() pour obtenir les dernières données de prix (bougies fermées uniquement).
  • • Calcul des indicateurs : Il utilise talib pour calculer le croisement des moyennes mobiles (ma_short, ma_long), l'indice de force relative (rsi), les Bandes de Bollinger (upper_band) et l'ATR (atr) pour le position sizing et le stop-loss dynamique.
  • • Logique de trading : Le bot vérifie les conditions d'achat et de vente, puis place les ordres.
  • • Pause : Le bot fait une pause de 60 secondes pour ne pas surcharger les serveurs.
  • • Gestion des erreurs : Les blocs `try...except` entourent les opérations critiques pour que le bot ne s'arrête pas en cas de problème.

Stratégies de Trading

Stratégie d'achat

  • •

    Croisement des Moyennes Mobiles (MA) : La MA courte (20 périodes) doit être supérieure à la MA longue (50 périodes).

  • •

    Indice de Force Relative (RSI) : Le RSI (14 périodes) doit être inférieur à 70 pour éviter le surachat.

  • •

    Bandes de Bollinger : Le prix actuel doit être inférieur à la bande supérieure pour éviter les sommets de volatilité.

Stratégie de vente

  • •

    Prise de profit (Take Profit) : Vente si le prix atteint +3 % au-dessus du prix d'achat (+ frais).

  • •

    Stop-loss suiveur (ATR) : Le stop est placé à ATR_MULTIPLIER × ATR sous le plus haut atteint depuis l'achat ; il remonte automatiquement avec le prix (trailing stop dynamique).

Disjoncteur de perte journalière

Un circuit breaker automatique surveille le capital USDT toutes les 60 secondes. Si la perte dépasse 5 % du solde de référence en moins de 24 heures, tous les nouveaux ordres sont suspendus jusqu'à la fin de la fenêtre courante.

  • • Référence glissante : le solde de référence est remis à jour toutes les 24 h ou après chaque réinitialisation du disjoncteur.
  • • Persistance : l'état du disjoncteur est sauvegardé dans bot_state.json — il survit aux redémarrages du bot.
  • • Reprise automatique : à l'expiration de la fenêtre, le trading reprend et un nouveau solde de référence est enregistré.
  • • Paramètre ajustable : CIRCUIT_BREAKER_DAILY_LOSS_PCT dans bot_trading.py (défaut : 0.05).
